## SpineSense setup

Set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` in
`frontend/.env.local` to enable account authentication and saved user data.
Apply the SQL migrations in `../supabase/migrations` to your Supabase project in
filename order. Migration `002_posture_sessions.sql` adds the posture history
table, row-level access policies, and the audio-volume preference field.

The public guest demo is available at `/demo`. The live session, personal
dashboard, and settings routes (`/session`, `/dashboard`, and `/settings`)
require a signed-in account.
